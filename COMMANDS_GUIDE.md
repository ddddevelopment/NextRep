# Руководство по командам Telegram-бота

Этот файл содержит описание всех доступных команд для управления вашим ботом для отслеживания тренировок.

## Основные команды

### `/start`
Начинает взаимодействие с ботом и показывает приветственное сообщение.
- **Использование:** Просто отправьте команду `/start`.

### `/help`
Показывает краткую справку по основным командам.
- **Использование:** Просто отправьте команду `/help`.

### `/menu`
Отображает главное меню бота с основными разделами.
- **Использование:** Просто отправьте команду `/menu`.

## Управление пользователем

### `/register`
Регистрирует нового пользователя в системе.
- **Формат:** `/register email password имя фамилия телефон`
- **Пример:** `/register user@example.com mypassword Иван Петров +79991234567`
- **Внимание:** Рекомендуется удалить сообщение с паролем после регистрации.

### `/login`
Авторизует существующего пользователя.
- **Формат:** `/login email password`
- **Пример:** `/login user@example.com mypassword`
- **Внимание:** Рекомендуется удалить сообщение с паролем после входа.

### `/logout`
Выход пользователя из системы. Завершает текущую сессию.
- **Использование:** Просто отправьте команду `/logout`.

### `/profile`
Показывает информацию о вашем профиле.
- **Использование:** Просто отправьте команду `/profile`.

## Управление упражнениями (ExerciseInfo)

Это команды для управления "шаблонами" упражнений в вашей личной библиотеке.

### `/create_exercise_info`
Создает новое упражнение.
- **Формат:** `/create_exercise_info "Название" "Группа мышц" "Описание (необязательно)"`
- **Группы мышц:** `Chest`, `Back`, `Shoulders`, `Biceps`, `Triceps`, `Legs`, `Core`.
- **Пример:** `/create_exercise_info "Жим лежа" "Chest" "Классическое упражнение для груди"`

### `/get_all_exercise_infos`
Показывает полный список всех созданных вами упражнений и их ID.
- **Использование:** Просто отправьте команду `/get_all_exercise_infos`.

### `/get_exercise_info_by_id`
Показывает детальную информацию о конкретном упражнении по его ID.
- **Формат:** `/get_exercise_info_by_id <ID упражнения>`
- **Пример:** `/get_exercise_info_by_id xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

### `/update_exercise_info`
Обновляет существующее упражнение.
- **Формат:** `/update_exercise_info <ID> "Новое название" "Новая группа мышц" "Новое описание (необязательно)"`
- **Пример:** `/update_exercise_info xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx "Жим лежа V2" "Chest"`

### `/delete_exercise_info`
Удаляет упражнение из вашей библиотеки.
- **Формат:** `/delete_exercise_info <ID упражнения>`
- **Пример:** `/delete_exercise_info xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

## Тренировки и статистика

### `/workouts`
Переход в раздел управления вашими тренировками (создание, просмотр, редактирование).
- **Использование:** Просто отправьте команду `/workouts`.

### `/stats`
Показывает вашу статистику по выполненным тренировкам.
- **Использование:** Просто отправьте команду `/stats`.

### 🏋️‍♂️ Управление тренировками

`/workouts` - получить список ваших тренировок.
`/create_workout "Имя тренировки" ["заметки"]` - создать новую тренировку.
`/get_workout_by_id <ID>` - получить детальную информацию о тренировке.
`/update_workout <ID> "Новое имя" ["новые заметки"]` - обновить имя и/или заметки для существующей тренировки.
`/delete_workout <ID>` - удалить тренировку.

### 🤸 Управление упражнениями в тренировке

`/add_exercise_to_workout <ID тренировки> <ID упражнения> ["заметки"]` - добавить упражнение в тренировку.
`/get_exercises <ID тренировки>` - получить список упражнений в конкретной тренировке.
`/update_exercise <ID тренировки> <ID упражнения> ["новые заметки"]` - обновить заметки для упражнения в тренировке.
`/delete_exercise <ID тренировки> <ID упражнения>` - удалить упражнение из тренировки.
`/get_exercise_by_id <ID тренировки> <ID упражнения>` - получить детальную информацию о конкретном упражнении.

### 📝 Управление подходами

- `/get_sets <ID тренировки> <ID упражнения>` - получить список подходов для конкретного упражнения. Отображает ID и заметки для каждого подхода.
  - **Пример:** `/get_sets <workout_id> <exercise_id>`

- `/add_set <ID тренировки> <ID упражнения> [вес] [повторения] ["заметка"]` - добавить новый подход к упражнению.
  - Заметку необходимо передавать в двойных кавычках.
  - **Пример:** `/add_set <workout_id> <exercise_id> 80.5 12 "Отличный подход!"`

- `/update_set <ID тренировки> <ID упражнения> <ID подхода> [новый вес] [новые повторения] ["новая заметка"]` - обновить существующий подход.
  - Хотя бы один из необязательных параметров (вес, повторения, заметка) должен быть указан.
  - **Пример:** `/update_set <workout_id> <exercise_id> <set_id> 82.5 10 "Заменил заметку"`

- `/delete_set <ID тренировки> <ID упражнения> <ID подхода>` - удалить подход из упражнения.
  - **Пример:** `/delete_set <workout_id> <exercise_id> <set_id>`
